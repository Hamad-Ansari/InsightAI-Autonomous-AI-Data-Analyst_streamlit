1. Introduction

InsightAI is a business-friendly, local AI data analyst. You upload a tabular file and it automatically understands it, cleans it, explores it across four dimensions (composition, distribution, comparison, relationship), runs sentiment and time-series analysis when relevant, detects anomalies, and then uses a local LLM (Ollama) plus a RAG knowledge base to explain everything in plain business language.

It is designed to run on your own laptop, uses free/open-source components, and keeps your data on your machine.

2. What InsightAI does

  • Detects the dataset structure, column types, missing values, duplicates and outliers.
  • Automatically cleans safe problems (without overwriting your original file).
  • Performs automated EDA and generates interactive charts.
  • Organises findings into Composition · Distribution · Comparison · Relationship.
  • Runs sentiment analysis on text, time-series analysis on dates, and anomaly detection.
  • Uses Ollama + RAG to turn numbers into understandable business insights.
  • Builds an executive dashboard and a final report (HTML / PDF / JSON / CSV).

4. Installing Python

  1. Go to python.org/downloads and download the latest stable installer.
  2. On Windows, tick “Add Python to PATH”.
  3. Run the installer and click Install Now.
  4. Verify:
python --version
pip --version

5. Installing Ollama

Ollama runs models locally. Install from ollama.com.

# After installing, start the server
ollama serve
The server default URL is http://localhost:11434.

6. Installing an Ollama model

ollama pull llama3.1:8b

Use a lighter model on limited hardware:

ollama pull llama3.2:3b

7. Downloading the project

git clone https://github.com/your-org/InsightAI.git
cd InsightAI

Or download the ZIP from your Git host and extract it.

8. Creating a virtual environment

A virtual environment keeps the project’s dependencies isolated from the rest of your machine.

python -m venv .venv

9. Activating the virtual env (Windows)

.venv\Scripts\activate

On macOS / Linux:

source .venv/bin/activate

You should see (.venv) at the start of your prompt.

10. Installing requirements

pip install -r requirements.txt

This installs Streamlit, pandas, scikit-learn, statsmodels, Plotly, reportlab, and others. Heavy optional packages (sentence-transformers, chromadb) are used if present and fall back gracefully if not.

cp .env.example .env

12. Starting Ollama

ollama serve

Leave this terminal open. InsightAI will detect it on the Settings page.

13. Running the Streamlit app

streamlit run app.py

Your browser opens at http://localhost:8501.

14. Uploading a dataset

  1. Use the Upload dataset widget in the sidebar.
  2. Choose a CSV, XLSX, XLS, TSV or Parquet file.
  3. InsightAI loads, validates and analyses it automatically.
  4. You can also click “Load a sample dataset” on the Home page to try it immediately.

15. Understanding the dashboard

The dashboard shows KPI cards (records, columns, data-quality score, missing values, duplicates, numeric/categorical/date columns) and sections for Dataset Health, Business KPIs, Composition, Distribution, Comparison, Relationships, Sentiment, Time Series, Anomalies and AI Insights.

16. Data cleaning

The Data Cleaning page shows exactly what was changed and why (a cleaning log). Outliers are reported but never deleted by default; you choose Keep / Remove / Winsorise in Settings & re-run.

17. EDA

The EDA page shows univariate statistics (numeric, categorical, text) plus an interactive chart builder where you pick the X/Y axis, colour, aggregation and chart type; InsightAI recommends the best chart for the data types.

18. Composition analysis

Answers “what is this data made of?” with donut, treemap and stacked-bar charts of category/segment/region shares.

19. Distribution analysis

Answers “how are values spread?” with histograms, KDE, box and violin plots, plus skewness, kurtosis and percentile stats.

20. Comparison analysis

Answers “how do groups differ?” with bar and ranking charts comparing a metric across categories (revenue by region, etc.).

21. Relationship analysis

Answers “how are variables connected?” with correlation heatmaps, scatter plots, regression lines and Cramér’s V for categories.

22. Sentiment analysis

If your data has text (reviews/comments/feedback), InsightAI scores sentiment using a local lexicon, and shows positive/neutral/negative percentages, common terms and themes.

23. Time-series analysis

If a date column exists, InsightAI aggregates by day/week/month, shows trend, growth, seasonality and moving averages, and can forecast (naive, moving average, Exponential Smoothing, ARIMA). Historical analysis and forecasting are kept separate.

24. RAG

The RAG Knowledge page exposes the curated methodology knowledge base (EDA, statistics, cleaning, visualization, time-series, sentiment, KPIs, industry guidance). RAG retrieves relevant chunks to ground the AI explanations.

25. AI insights

The AI Insights page returns structured output: Executive Summary, Top 5 Findings, Data Quality, Trends, Risks, Opportunities, Recommendations and Further Questions — generated by Ollama (or the deterministic fallback).

26. Generating reports

Go to Final Report and click Generate HTML report. The report is produced instantly and can be exported as HTML, PDF, JSON and CSV.

27. Downloading results

The Export page lets you download the cleaned CSV, the HTML/PDF report, the machine-readable JSON results and a summary CSV.

28. Troubleshooting

Ollama not detected — run ollama serve, pull a model, then reload Settings.
Slow analysis on big data — use the Sampling option in Settings (e.g. 25%).
Report images missing — install pip install kaleido to embed charts.
Sentiment not shown — your data needs a text/review/comment column.

30. Project architecture

Layered: ingestion → cleaning → analysis → visualization → rag → llm → reporting, orchestrated by the agent. See the README structure diagram.

31. Privacy & security

  • Data is processed locally; nothing is sent to external APIs by default.
  • Uploaded files are never executed as code; extensions and sizes are validated.
  • API keys live in .env and are never committed.
  • Dataset statistics go only to a local Ollama server.

32. Limitations

  • LLM quality depends on the model you run locally.
  • Sentiment uses a lightweight lexicon; heavy fine-tuned models may be better for difficult text.
  • Forecasts are estimates, not certainties.
  • Very large datasets benefit from sampling for speed.

34. Best practices

  • Start with a clean, single-table CSV for the most predictable results.
  • Give columns meaningful names — schema detection uses names (e.g. price, customer_id, date).
  • Review the cleaning log; InsightAI never silently modifies anything.
  • Validate AI findings against domain knowledge before acting on them.
  • Use Forecasting only on enough history (months of data).
